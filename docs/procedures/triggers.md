# Trigger publication and acknowledgement

The Agent and Provider maintain a long-lived bidirectional trigger stream.
Providers publish normalized, manifest-declared events with stable publication
identities; the Agent validates, forwards, and acknowledges each publication
without assigning StateForge project or component meaning inside SFP.
